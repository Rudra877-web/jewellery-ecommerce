1. System Overview & The 5 Core Workflows

Jewellery Mate is a custom Next.js e-commerce application tailored specifically for royal Indian fine jewellery. It combines spreadsheet-based inventory synchronization with high-conversion storefront UX, multi-item logistics, and instant messaging notifications.

1. Home Showcase Experience

Full-width promotional hero slider with animated luxury CTAs, dynamic category count showcases, and live bestseller ranking engine.

2. Attribute Filtering Engine

Faceted real-time filter navigation: Metal, Purity, Gemstones, Occasion, Gender, Price & Weight range sliders with URL synchronization.

3. Google Sheets Auto-Sync

Zero-friction catalog deployment from Google Sheets / Drive or direct CSV upload with smart header alias recognition and automated category creation.

4. Multi-Product Cart & Shiprocket

Multi-item cart drawer with instant subtotal and weight calculation, auto-dispatching orders to Shiprocket for real-time AWB and courier tracking.

5. Meta WhatsApp Cloud API Integration

Instant WhatsApp order confirmation dispatched to store owner (+91...) with itemized bill, customer shipping address, and 1-click direct customer messaging fallback.

2. Storefront Experience & Attribute Filter Engine

Feature 1: Home Page Gallery & Bestsellers

The home page (app/page.tsx) uses server-side dynamic rendering to guarantee fresh inventory data on every visit:

  • Hero Slider (components/home/HeroSlider.tsx): Full-bleed imagery, gold foil serif typography, slide indicators, and direct deep-links to categories. Managed via the HeroSlide database table.
  • Categories Grid (components/home/CategoriesSection.tsx): Renders circular and card category portals displaying live product count pills.
  • Best Selling Grid (components/home/BestSellingSection.tsx): Fetches top 8 products sorted by unitsSold (descending) and isBestseller flag. Includes quick view drawer and 1-click Add-to-Cart.

Feature 2: Category Attribute Filtering Engine

Located at components/category/CategoryView.tsx, the category engine evaluates products in real time across 7 distinct attribute facets:

Attribute Supported Values Behavior
Metal Gold, Silver, Platinum, Diamond Multi-select filter matching product metal type
Purity 18K, 22K, 24K, 925 Filters by gold or silver karat hallmark
Gemstones Diamond, Kundan, Emerald, Ruby, None Filters stones embedded in the jewellery
Occasion Bridal, Festive, Daily Wear, Party Curated lifestyle and styling filter
Gender Women, Men, Unisex Demographic classification
Price Slider Dynamic ₹ Min – ₹ Max Real-time range slider bounded to category price extrema
Weight Slider Dynamic 0g – 100g+ Filters by gross weight in grams
URL Query Synchronization: When customers toggle filters, the browser URL automatically updates (e.g. /category/rings?metal=Gold&purity=22K&inStock=true) without reloading the page. This ensures customers can bookmark or share exact filtered results.

3. Catalog Synchronization Engine (Google Sheets & CSV)

The catalog sync engine (lib/catalog-sync.ts) connects directly to Google Sheets or Google Drive CSV exports.

Smart Column Alias Recognition

To prevent errors from manual typing, the parser accommodates all common column variations:

Internal Field Accepted Spreadsheet Column Names Default Fallback
sku sku, item code, product id, code, item no, product code Required
name name, product name, title, item name, design name Required
category category, category name, type, collection, department Required
price price, selling price, sale price, rate, amount, offer price Required (> 0)
mrp mrp, regular price, original price, list price, market price Defaults to price
stock stock, quantity, qty, inventory, available stock Defaults to 10

4. Multi-Product Cart & Shiprocket Logistics Engine

The checkout flow (app/checkout/page.tsx) handles multi-product carts with automatic logistics provisioning.

Shiprocket Fulfillment Flow

  1. Adhoc Order Creation: System submits an order bundle to /v1/external/orders/create/adhoc with total weight, dimensions, and customer address.
  2. Shipment ID: Shiprocket returns a unique order_id and shipment_id.
  3. AWB Generation: System immediately triggers /v1/external/courier/assign/awb.
  4. Live Tracking: When allocated, the AWB code (e.g. AWB12345678) is attached to the order with a direct tracking URL (https://shiprocket.co/tracking/...).
Why AWB can show "Pending": Shiprocket mandates: (1) Prepaid wallet balance (minimum ₹100), and (2) Approved domestic KYC. If wallet balance is 0, Shiprocket registers the order but pauses AWB. In your Admin Orders panel (/admin/orders), the owner sees SR #[ID] (AWB Pending) and can click "Retry Shiprocket Order" as soon as the wallet is recharged.

1-Click Direct WhatsApp Fallback

In addition to automated Cloud API messages, the Admin Orders table features a direct wa.me shortcut. Store managers can click "1-Click WhatsApp to Customer" from any device to send invoices, dispatch confirmations, and delivery updates directly.
