2. Discovered Defects, Root Causes & Resolutions

BUG-01: Unauthenticated Guest Access to Store Admin Console (/admin/*) SEVERITY: CRITICAL
Module: Admin Portal • Root Cause: app/admin/layout.tsx rendered admin navigation without verifying session cookie or redirecting unauthenticated visitors to /admin/login.

An unauthenticated visitor navigating directly to /admin could inspect revenue metrics, order quantities, and catalog data without entering the admin password.

✓ Fix Implemented & Verified: Created /api/admin/auth/me, added authorization verification in app/admin/layout.tsx, and enforced server-side redirect guard via checkAdminSession() in app/admin/page.tsx. Retested via TC-28: unauthenticated visitors are immediately halted and redirected to /admin/login.
BUG-02: Unprotected Administrative Mutation Endpoints (/api/admin/*) SEVERITY: HIGH
Module: Backend API Security • Root Cause: While settings endpoints enforced checkAdminSession(), endpoints in orders/route.ts, products/route.ts, slider/route.ts, and sync/* allowed unauthenticated operations.

Raw customer personal data and order records could be extracted by unauthenticated GET requests, and catalog products could be inserted or patched without credentials.

✓ Fix Implemented & Verified: Injected checkAdminSession() guard returning 401 Unauthorized across all administrative routes. Verified via TC-40.
BUG-03: Soft Navigation Cart State Desync on Checkout Submission SEVERITY: MEDIUM
Module: Checkout Flow • Root Cause: router.push(data.redirectUrl) failed to perform an atomic flush of cart state across all client browser windows upon order completion.

Upon order completion, stale in-memory cart states occasionally lingered or failed to navigate reliably in automated browser environments.

✓ Fix Implemented & Verified: Upgraded navigation callback to deterministic window.location.href = data.redirectUrl in app/checkout/page.tsx, guaranteeing atomic cart clearing, confetti trigger, and redirection to /order-success/[orderNumber]. Retested via TC-18.
